# MegaMinds Tech Assignment

## Tech Stack
- ASP.NET Core MVC
- SQL Server (Stored Procedures)
- jQuery, Bootstrap

## Features
- Modal-based User Registration Form
- AJAX CRUD Operations (Insert, Update, Delete, List)
- State-City dependent dropdown
- Form validation using jQuery

## Architecture
- Layered Architecture
- Repository Pattern
- Separate BLL and DAL

## Database
- tblUserRegistration
- tblState
- tblCity

## How to Run
1. Execute Database.sql in SQL Server
2. Update connection string in appsettings.json
3. Run the project

## Git Flow
- Main branch: final code
- RegistrationForm: feature development
